# Guanioma Pereira (@guniomapl) — Proyectos y Landing Pages

Repositorio oficial para proyectos web y páginas de aterrizaje de Guanioma Pereira.

## Estructura del Repositorio

- **`megapack/`**: Landing page oficial de alta conversión para la colección *"Masajes 9 en 1"* (Next.js 16 + React + TypeScript + CSS personalizado), con integración directa a Hotmart y canal de atención en WhatsApp para Venezuela (+58 414-7017139).
- **`DrenajeLinfatico/`**: Módulo en desarrollo para contenidos y promociones de drenaje linfático.

## Desarrollo Local (Megapack)

Para correr la landing page de Masajes 9 en 1:

```bash
cd megapack
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) o el puerto asignado en tu navegador.
