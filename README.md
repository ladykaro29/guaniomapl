# Guanioma Pereira (@guniomapl) — Proyectos y Landing Pages

Repositorio oficial para proyectos web y páginas de aterrizaje de Guanioma Pereira.

## Estructura del Repositorio

- **`megapack/`**: Portal principal y aplicación web en Next.js 16 + React 19 + TypeScript:
  - `/` -> Hub central de marcas y proyectos de Guanioma Pereira.
  - `/megapack` -> Landing page oficial para la colección *"Masajes 9 en 1"*.
  - `/drenaje-linfatico` -> Landing page de alta conversión para el curso *"Drenaje Linfático: Tu Secreto de Belleza"* de Ana María ($10 USD / 90% OFF).
  - Integración directa con pasarela de Hotmart y canal de atención en WhatsApp para Venezuela (+58 414-7017139).
- **`DrenajeLinfatico/`**: Recursos, documentación y assets gráficos para el producto Drenaje Linfático.

## Desarrollo Local

Para correr el portal y las landing pages:

```bash
cd megapack
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) o [http://localhost:3000/drenaje-linfatico](http://localhost:3000/drenaje-linfatico).
